# Hero's Dice Tray

A free d20 dice tray for The Ashen Reach Chronicles and The Broken Compass, by Cipher & Compass.

- Works offline once it has been opened one time.
- No ads, no accounts, no tracking. Hero sheets are saved only on the player's own phone.
- Fonts: Alegreya, Alegreya SC and IBM Plex Mono, under the SIL Open Font License (see the `fonts` folder).

## Updating the app later
1. Upload the changed file to this repository (Add file, then Upload files).
2. Open `sw.js`, click the pencil, and change `dice-tray-v1` to `dice-tray-v2` (then v3, and so on).
   This tells phones to fetch the new version. Players see it the next time they open the app twice.
